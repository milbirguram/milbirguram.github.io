The observation that cannot settle it

In each world, 40% of people use and return, 10% use without returning, 10% return without using, and 40% do neither. Feature users return 80% of the time; non-users return 20%. Even unlimited observations of these two variables cannot distinguish these specified mechanisms.

Change the mechanism; change the prediction

Setting use to yes cuts its incoming arrows. World A then predicts an 80% return rate; B and C predict 50%. Setting return to yes instead separates C from A and B. Knowing the whole graph takes different evidence from answering one useful question.

What is inside these worlds?

A: use is a fair coin; return has probability 0.2 + 0.6 × use. B: readiness is a fair coin; use equals readiness; return has probability 0.2 + 0.6 × readiness. C: return is a fair coin; use has probability 0.2 + 0.6 × return. Each outcome uses fresh independent noise. Interventions perfectly set one variable and preserve the other equations.

The prior gives each world one third of the weight. Updates use the exact binomial likelihood of the observed count. Expected information is the average reduction in entropy, in bits, about your selected question. The suggestion maximises information per credit for the next experiment; it is a one-step choice, not an optimal plan for the full budget.

These are synthetic users and idealised interventions. In practice, “making someone return” may be impossible without changing other things. Costs are illustrative. High confidence here is conditional on just these three models, known parameters, independent samples, and perfect interventions. It does not establish the cause in a real product.

Inspired by the question-focused experiment design in Active Bayesian Causal Inference (Toth et al., 2022). This small finite model is not a reproduction of their Gaussian-process method.
