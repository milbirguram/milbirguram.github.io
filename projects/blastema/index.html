Blastema

A flatworm of over a thousand cells, each following the same few rules and reading only its six neighbours. Cut it, and each piece rebuilds a whole, smaller worm. Touch it with the rewrite brush, then cut again: the same cells with the same rules grow a second head, because the body’s target is held in the cells’ shared memory, not in a stored picture. This is a toy model inspired by planarian research, not a biological simulation; real regeneration is far more complex and partly unknown.
