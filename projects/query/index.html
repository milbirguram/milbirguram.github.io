    The result

    What is recorded, what runs here, and what was tested?

    The boundary is visible

    The 20 questions were answered by a Codex model session in three prompt setups. The recorded plan and short decision summary are replayed; they are not newly generated. The verification setup actually executed its proposed queries during capture.

    SQL runs now in an isolated SQLite WebAssembly worker against the frozen 344-row dataset. It accepts one SELECT, refuses writes, bounds memory/output and terminates a long query. Editing SQL does not ask the model to replan.

    The local planner is a small set of rules, available for new counts and averages. Unsupported questions should be taken to the SQL editor. It is not a general natural-language model.

    Small evidence, modest claim

    All three recorded setups passed 20/20 fixed checks: 17 query results and 3 necessary abstentions. One model and one small, visible set cannot establish a winning prompt or general reliability. Inspect the comparison in Trial →

    The data records sampled penguins in 2007–2009. Island, species and sex overlap; these rows do not establish causal effects or Antarctic population counts.
