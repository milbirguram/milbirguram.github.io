Whittle

Each function below has a small bug, and every example test passes anyway. State a property that should hold for every input, and a property-based tester will throw random inputs at the code until one fails, then whittle that failure down to the smallest input that still breaks it. The bugs are planted and the functions small. And a property that survives is not proven: it has only outlasted many honest attempts to refute it.
