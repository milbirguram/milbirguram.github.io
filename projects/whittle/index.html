        About the experiment
        
      These are real JavaScript tests, running in your browser. Each example contains a planted bug. Generated inputs look for a counterexample; the shrinker keeps simplifying it only when it still fails. The result is locally minimal for this shrinker, not necessarily the smallest possible input. A passing run is evidence, not proof.
      
        
      Inspired by QuickCheck and Hypothesis. The engine, methods and references are documented in the project notes.
