About the experiment
These are real, recorded model responses to synthetic database cases. You can inspect what each call saw, what it concluded, and which query results it pointed to. The browser replays those records; it does not run a live agent.
Solo sees its earlier answers. Independent analysts do not see each other; a deterministic majority vote chooses their final claim, with ties left unresolved. Relay passes earlier answers through an analyst, a critic, and an adjudicator. Each call starts with the same complete evidence packet.
Protocol, budgets, and limits
The experiment controls the number of model calls and the output-token ceiling. Prompt length and actual token use differ and are shown separately. Role prompts and selection rules differ too, so this comparison does not isolate communication alone.
Three tasks, one model, and one recorded run per setting are a collection of inspectable cases. They cannot establish which architecture is generally better. The model receives precomputed SQL evidence; it does not choose or execute tools. Correctness checks the selected hypothesis against the known injected cause, not the quality of every sentence in the explanation. After you check the cause, separately labelled editorial notes flag contradictions and unsupported details in the recorded responses. A cited query ID is checked for existence, not semantic support.
Research prompts: Towards a Science of Scaling Agent Systems and Why Do Multi-Agent LLM Systems Fail? Quorum is a small original experiment, not a reproduction of either benchmark.
