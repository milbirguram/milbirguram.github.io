    The record, retrieval method and limits

    An answer has a paper trail

    A Codex session used this exact lexical search tool to investigate seven questions. Its actual search queries, result IDs, answer segments and abstentions are preserved. Opening a question replays that answer and recomputes the searches locally.

    Search uses BM25 over 36-line chunks, overlapping by ten lines. It matches words, not semantic embeddings. Scores rank matches within a query; they are not confidence or proof that a question is answerable.

    Source is bounded and historical

    The snapshot is pinned to one commit. Read code when it disagrees with prose: the README says its workflow was not installed, but the pinned repository contains the workflow. A configured schedule is not evidence that it ran.

    The citation spans and search results were checked for this small record. Five supported answers and two refusals are examples, not a reliability estimate. Search matches for new questions require your interpretation.
