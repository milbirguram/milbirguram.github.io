# Portfolio guidance

## Other projects gallery order

The owner's standing preference for `projects.html`:

- Preserve the existing relative order of project cards.
- Keep **Stencil, Quorum, Warrant and Cardinal** as the final four cards, in that order.
- Insert future new project cards immediately before Stencil, after all preceding projects.
- Apply the same ordering to the gallery mirror in `milbirguram/other-projects`.

Follow this rule for future additions unless the owner explicitly requests a different order.

## Project interfaces

The owner prefers restrained, easy-to-understand interfaces. Lead with the main interaction and a short introduction. Use plain control labels, and put supporting methodology and long explanations behind optional disclosures. Preserve each project's character, functionality, meaningful results, data credits, and relevant qualifications.
